How to tune the buffers

The target is the average decoded audio queue. Lower it for less delay; raise it if playback drops out. Underruns cause silence while scrcpy gradually recovers.

Output buffer requests the device's processing block size. Keep 10ms initially. The audio backend may choose another size. There is no required ratio.

Start at 60/10 for stability, then lower the target in 10ms steps. Restart playback to apply new settings. The estimate reflects selected settings, not a running measurement.
